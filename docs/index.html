Kenapa berbeda

Dibangun seperti produk, bukan kumpulan skrip.

Arsitektur modular dengan lapisan browser-first, API tunggal, dan failover berlapis agar tetap hidup walau satu gateway tumbang.

PWA yang bisa dipasang

Manifest, service worker, dan ikon maskable sudah disiapkan. Pasang ke layar utama Android, iOS, maupun desktop — berjalan layaknya aplikasi native.

Deploy

Vercel serverless (api/index.js), Render, Railway, atau Docker node:20-alpine.

Runtime

Node.js ≥ 18, hanya satu dependensi produksi: express. Ringan dan mudah diaudit.

Data

State disimpan di penyimpanan JSON lokal, cocok untuk demo. Ganti ke basis data bila dipakai publik.

Quick start

Jalan dalam hitungan detik.

Salin perintahnya, atau deploy ke platform favoritmu.

bash 
# 1. ambil repositori
git clone https://github.com/daff4tech/daff4tech.git
cd daff4tech

# 2. pasang dependensi & jalankan
npm install
npm start

# → http://localhost:3000
